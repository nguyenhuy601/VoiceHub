# system design

## When to use

Greenfield module or significant redesign with options.

## When NOT to use

As-is documentation only (architecture-analysis).

## Related Rules

- `.cursor/rules/role-solution-architect.mdc`
- `.cursor/rules/voicehub-constraints.mdc`

## Input

Goals and constraints

## Workflow

1. Propose 2 options with pros/cons.
2. Respect service ownership and contracts.
3. Recommend decision with rationale.
4. No code unless requested.

## Expected output

Design options + recommendation

## Tools

Read, CreatePlan. Readonly preferred.
