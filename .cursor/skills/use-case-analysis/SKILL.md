# use case analysis

## When to use

Complex user or API flows need explicit use cases.

## When NOT to use

Simple CRUD with clear AC.

## Related Rules

- `.cursor/rules/senior-dev-engineering.mdc`

## Input

Feature description

## Workflow

1. Identify actors and goals.
2. Write main success scenario.
3. Alternate and exception flows.
4. Link to AC / API endpoints when known.

## Expected output

Use case set

## Tools

Read, Grep.
